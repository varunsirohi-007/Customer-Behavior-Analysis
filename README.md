# 📊 Customer Behavior Analysis Dashboard

An interactive data analytics project that transforms raw customer shopping data into meaningful business insights using **Python, SQL, and Power BI**.

---

## 🚀 Project Overview

This project focuses on analyzing customer purchasing behavior to help businesses:

* Understand customer patterns
* Identify high-value and repeat customers
* Improve decision-making with data-driven insights

The final output is an **interactive Power BI dashboard** for easy visualization and exploration.

---

## 🛠️ Tech Stack

* **Python (Pandas)** – Data cleaning, preprocessing, and transformation
* **SQL** – Extracting business insights and analytical queries
* **Power BI** – Interactive dashboards and visual storytelling
